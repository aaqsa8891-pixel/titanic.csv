# 🚢 Titanic Survival Analysis

Exploratory data analysis on the classic Titanic passenger dataset — investigating which factors most influenced a passenger's chance of survival.

## 📌 Overview
This project explores the Titanic dataset using Python to uncover patterns in survival rates across passenger class, age, gender, and family size. It's part of my hands-on practice as an AI & Data Science student.

## 🛠️ Tools & Libraries
- Python
- pandas
- NumPy
- Matplotlib / Seaborn (for visualization)

## 📊 What I Did
- Cleaned and prepared the raw passenger dataset
- Handled missing values (age, cabin, embarked)
- Explored survival rate by class, gender, and age group
- Visualized key patterns and relationships in the data

## 💡 Key Takeaways
- Passenger class and gender were strong indicators of survival
- Data cleaning is a critical first step before any analysis
- Practiced translating raw statistics into a clear, human-readable story
